# Tiaanso Global — Design, Stock & Orders

Sales-assisted catalog for **Tiaanso Global**. A Design Card binds studio photos, live stock, WhatsApp share, and order taking — so a customer request is no longer “hunt a tablet folder, then type stock, then take the order in another chat”.

## Read this first

The solution flow (roles, capture → share → order, and why it replaces folders) is in [`SOLUTION_FLOW.md`](./SOLUTION_FLOW.md).

## Demo

Open [`demo/index.html`](./demo/index.html) in a browser (tablet-sized window is best).

1. **Flow** — the journey, before you click around
2. **Capture** — shoot or upload into a design code (not a folder)
3. **Catalog** — search a design, see stock, share pack, add to order
4. **Orders** — confirmed orders reserve color × size quantity

No server is required. Sample designs and customers are in the page. Confirmed orders are stored in the browser.

## Roles in the demo

| Role | What to try |
| --- | --- |
| Sales | Catalog → open a card → Share design + stock → Add to order |
| Studio tablet | Capture → pick a design → shutter or upload |
| Warehouse | Catalog → open a card → +/- on the stock matrix |
